❓1. What is multithreading?

Answer:
Multithreading is a process of executing multiple threads concurrently within a single program to improve performance and responsiveness.

⚙️ CORE CONCEPT QUESTIONS
❓5. What is synchronization?

Answer:
Synchronization is a mechanism to control access of multiple threads to shared resources to avoid data inconsistency.

❓6. What is a race condition?

Answer:
When multiple threads access and modify shared data simultaneously, leading to unpredictable results.

❓7. Difference between synchronized and Lock?
synchronized	Lock

Less flexible	More control
Auto release	Manual release
❓8. What is volatile?

Answer:
Ensures visibility of changes to variables across threads.

volatile boolean flag = true;

👉 Guarantees latest value is read.

⚡ ADVANCED QUESTIONS
❓14. What is Deadlock?

Answer:
A situation where two or more threads are waiting for each other’s resources forever.

❓15. What is Starvation?

Answer:
A thread does not get CPU time due to higher priority threads.

❓16. What is Livelock?

Answer:
Threads keep responding but no progress happens.

🧪 PRACTICAL CODING QUESTIONS
❓19. Print numbers using 2 threads alternately
class AlternatePrint {
    private static final Object lock = new Object();
    private static int count = 1;

    public static void main(String[] args) {
        Runnable task = () -> {
            while (count <= 10) {
                synchronized (lock) {
                    System.out.println(Thread.currentThread().getName() + " " + count++);
                    lock.notify();
                    try {
                        lock.wait();
                    } catch (InterruptedException e) {}
                }
            }
        };

        new Thread(task, "T1").start();
        new Thread(task, "T2").start();
    }
}
❓20. Producer-Consumer Problem
BlockingQueue<Integer> queue = new ArrayBlockingQueue<>(5);

// Producer
new Thread(() -> {
    try {
        for (int i = 0; i < 10; i++) {
            queue.put(i);
            System.out.println("Produced: " + i);
        }
    } catch (Exception e) {}
}).start();

// Consumer
new Thread(() -> {
    try {
        while (true) {
            System.out.println("Consumed: " + queue.take());
        }
    } catch (Exception e) {}
}).start();
